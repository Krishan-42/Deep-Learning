# Perceptron Demo

## Overview
This project demonstrates the implementation of a Perceptron, one of the simplest artificial neural network models. It introduces the basic concepts of supervised learning and how a model learns to classify data using input features.

## Objectives
- Understand the working of a perceptron.
- Learn how weights and bias are updated during training.
- Implement a basic classification model.
- Understand the fundamentals of neural networks.

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn (if used in the notebook)

## How to Run
1. Clone or download this repository.
2. Open `Perceptron.ipynb` in Google Colab or Jupyter Notebook.
3. Upload or load the required dataset.
4. Run the notebook cells in order to train and test the model.

## Key Concepts
- Perceptron learning algorithm
- Weights and bias
- Activation function
- Model training and prediction
- Binary classification

## Learning Outcome
This demo provides a basic understanding of how a perceptron learns from data and forms the foundation for studying more advanced neural networks and deep learning models.
